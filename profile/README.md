## Start building

Follow the [quickstarts](https://www.thruput.network/docs/get-started/)
or [build with an agent](https://www.thruput.network/docs/start/build-with-an-agent/).

| Repository | Purpose |
| --- | --- |
| [thruput-tools](https://github.com/thruputchain/thruput-tools) | CLI, JSON-RPC gateway, and developer tools |
| [thruput-sdk-rs](https://github.com/thruputchain/thruput-sdk-rs) | Rust smart contract SDK |
| [thruput-sdk-ts](https://github.com/thruputchain/thruput-sdk-ts) | TypeScript client |
| [hogd](https://github.com/thruputchain/hogd) | Core execution engine and node runtime |
| [thruput-docs](https://github.com/thruputchain/thruput-docs) | Website and developer documentation |
